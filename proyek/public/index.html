1. Template Gelang Barcode

Format gelang acara wisuda berukuran presisi (260mm x 25mm). Siap cetak di kertas A4 / Tyvek gelang, lengkap dengan QR Code, Barcode, nama wisudawan, dan status kerja.

2. Layar Tampilan Panggung

Halaman visual megah untuk proyektor / videotron panggung utama. Menampilkan wisudawan saat gelang/barcode discan, lengkap dengan lonceng dan ucapan nama otomatis (TTS).

3. Panel Operator Scan

Halaman untuk panitia pemanggil wisudawan di meja scan. Mendukung pemindai barcode USB/Bluetooth gun fisik, pendaftaran mahasiswa, import CSV, dan pengaturan panggung.

4. Kartu Barcode Wisudawan

Kartu identitas tanda peserta wisuda format ID Card standar (portrait), lengkap dengan foto, barcode Code128, dan QR Code untuk pengujian atau cetak ID card fisik.
